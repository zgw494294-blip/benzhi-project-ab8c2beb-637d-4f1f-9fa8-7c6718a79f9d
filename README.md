# 口述史授权净化发布台

这是一个面向口述史资料馆的本地浏览器工作台，用于管理访谈转写文本从授权登记到脱敏发布的完整证据链。系统支持授权连续修订及收紧影响重检、稳定段落批量修订、敏感标注批量预检、确定性脱敏与残余风险报告、复核任务批量裁决、审计链完整性诊断、冻结批准，以及带内容摘要、授权摘要和审计摘要的发布清单。系统不保存音频本体，也不连接外部服务。

## 构建

项目使用 Go 1.22 或更新版本，不需要 Node.js 或前端构建链：

```text
go build ./cmd/server
```

## 运行

默认只监听高位回环地址 `127.0.0.1:19081`，数据写入当前目录的 `data/`：

```text
go run ./cmd/server
```

也可以明确指定回环监听地址和数据目录：

```text
go run ./cmd/server -addr=127.0.0.1:19092 -data=./local-data
```

如果没有提供 `-addr`，可设置 `PORT` 为端口号，服务将监听 `127.0.0.1:<PORT>`。服务拒绝非回环 IP、主机名、零端口和格式无效的地址。浏览器访问服务根路径即可使用完整工作台。

## 业务流程

1. 建立档案，填写受访者代号、采访日期、用途和整理员。
2. 登记允许用途、禁用主题、姓名披露规则和可选封存截止日期；每次保存形成连续授权修订，规则收紧会定位受影响段落与标注。
3. 以稳定编号逐段或批量录入转写；按 Unicode 字符位批量预检敏感标注的命中原文、处置结果、重叠和授权策略后再原子提交。
4. 提交净化并生成差异预览与覆盖度报告；阻断级残余风险、越界、重叠、无效处置或旧段落处理摘要会阻止进入复核。
5. 复核员可从任务队列筛选待办，并在同一档案版本内批量确认或逐项填写理由退回。退回后只能修订受影响段落，未受影响的已通过结果会保留。
6. 全部复核通过后冻结版本，由发布负责人批准、下载并验证发布清单。
7. 在“审计时间线”按操作人、动作、版本和时间筛选分页，查看原始序号、全链完整性、首个异常位置及发布清单审计摘要核对结果。

本地持久化由 `data/archives/` 原子 JSON 快照、`data/audit/` 仅追加 JSONL 审计日志和 `data/manifests/` 发布清单组成。多人修改通过 `expectedVersion` 检测覆盖冲突；重复动作可携带 `actionKey` 复用首次结果。

## 测试与自检

运行全部单元测试和集成测试：

```text
go test ./...
```

在指定真实回环端口执行有界 HTTP 全流程自检；命令会自行关闭服务并退出：

```text
go run ./cmd/server -addr=127.0.0.1:19091 -selfcheck
```

自检覆盖建档、授权、转写、两类敏感标注、脱敏、逐项复核、冻结、批准、清单离线摘要验证和最终档案读取。回归测试还覆盖授权并发冲突与影响重检、批量段落原子失败、标注预检、残余风险稳定摘要、复核队列批量裁决，以及筛选条件不能掩盖审计链损坏。
